# Palette Pocket

A lightweight color palette generator built with vanilla HTML, CSS, and JavaScript.

## Features
- Generate five-color palettes
- Lock favorite colors while regenerating others
- Copy HEX color codes
- Save, restore, and delete palettes
- Press Space to generate a new palette
- Responsive desktop and mobile layout
- Save collections with browser localStorage

## Run locally
Clone or download this repository and open `index.html` in a modern browser. No dependencies, build tools, or API keys are required.

## Tech stack
HTML5, CSS3, vanilla JavaScript, localStorage, Clipboard API.

## Project structure
`index.html` · `style.css` · `app.js` · `README.md` · `LICENSE` · `.gitignore`

## Privacy
Saved palettes remain in local browser storage on the device being used.
